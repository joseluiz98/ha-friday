# F.R.I.D.A.Y. 0.4.4: clean announcements, music back on the office satellite, and an orange update light

This release makes satellite announcements play clean, brings music back on the office satellite after its reboot, and gives the update and setup lights a dimmed orange. It also carries everything in v0.4.3, which had not been promoted yet.

- Announcements no longer click before the speech or hiss after it, on every satellite.
- Announcements already said before are spoken again once with the clean audio, then reused.
- Music plays on the office satellite again, also after a reboot, and a made-up music player is corrected to the satellite's own.
- Update and setup show a slow dimmed orange on the ring.

## New features
- **Dimmed orange for update and setup.** On the XVF ring, an update waiting and the setup mode breathe slowly in a dimmed orange; installing uses the same orange, faster, still slower than the alarm. Yellow is kept for the coming notifications. (#54)

## Fixes
- **Music stopped on the office satellite after its 22/11 reboot.** The music player runs as another user and could not follow `/etc/asound.conf` into `/etc/friday-satelite`, which is closed to everyone else, so it restarted in a loop. The audio board files now live in `/etc/friday-audio`, readable by the player; a migration moves existing satellites and restarts the player, keeping the old files for a rollback. (#54)
- **The voice invented a music player.** Asked for "my Deezer Flow", the voice model sometimes made up a player name from the satellite's name. A music request now uses the satellite's own player instead of the invented one, answers at once when the player is unavailable, and lets the request through unchanged if Home Assistant takes longer than a second to answer. (#54)
- **The brain could not reach Home Assistant.** OpenClaw's Code Mode ran without the environment the Home Assistant calls need; it is now off and the brain calls Home Assistant through `exec`. (#54)
- **The Alpha promotion sensor showed the wrong alpha.** It showed the newest alpha ("tomorrow") while an older one was promoted at lunch; it now shows the alpha promoted first. The promotion itself is unchanged. (#54)
- **Every announcement clicked before the speech and hissed after it.** The voice model returns a complete audio file, and the server played its header and its closing metadata as sound, near full volume. On 22/11 every saved announcement started with the file header and ended with about 120 bytes of metadata. Now only the audio is played; an audio file that cannot be read fails the announcement instead of playing noise. Saved announcements made before this release are not reused, and the server now keeps the last 100 announcements instead of 200. (#51)

## Changes by area
