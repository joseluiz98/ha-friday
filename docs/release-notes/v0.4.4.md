# F.R.I.D.A.Y. 0.4.4: announcements without the click and the hiss

This release makes satellite announcements play clean, with nothing before or after the speech. It also carries everything in v0.4.3, which had not been promoted yet.

- Announcements no longer click before the speech or hiss after it, on every satellite.
- Announcements already said before are spoken again once with the clean audio, then reused.

## Fixes
- **Every announcement clicked before the speech and hissed after it.** The voice model returns a complete audio file, and the server played its header and its closing metadata as sound, near full volume. On 22/11 every saved announcement started with the file header and ended with about 120 bytes of metadata. Now only the audio is played; an audio file that cannot be read fails the announcement instead of playing noise. Saved announcements made before this release are not reused, and the server now keeps the last 100 announcements instead of 200. (#51)

## Changes by area
- Voice gateway (VM): announcement audio without the file header and metadata; saved announcements made again; keeps the last 100. (#51)
- **Migrations:** none.
