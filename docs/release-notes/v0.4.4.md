# F.R.I.D.A.Y. 0.4.4: clean announcements, music back on the office satellite, and voice learning for every wake word

This release makes satellite announcements play clean, brings music back on the office satellite after its reboot, makes the voice-learning program work on any satellite (new ones included) and for every wake word, and gives the update and setup lights a dimmed orange. It also carries everything in v0.4.3, which had not been promoted yet.

- Announcements no longer click before the speech or hiss after it, on every satellite.
- Announcements already said before are spoken again once with the clean audio, then reused.
- Music plays on the office satellite again, also after a reboot, and a made-up music player is corrected to the satellite's own.
- Update and setup show a slow dimmed orange on the ring.
- The voice-learning program no longer needs the October archive that only the office satellite has, and a satellite without enough ambient recording of its own borrows negatives from the others.
- One voice-learning session now teaches your voice for Friday and Sexta-feira, each judged on its own.
- The assistant no longer says things like "the satellite will conduct the process".

## New features
- **Dimmed orange for update and setup.** On the XVF ring, an update waiting and the setup mode breathe slowly in a dimmed orange; installing uses the same orange, faster, still slower than the alarm. Yellow is kept for the coming notifications. (#54)
- **Baseline of negatives for new satellites.** With less than 30 minutes of its own ambient audio, a satellite asks the server for negatives from the other satellites (their ambient recordings and the false activations they were taught) when the voice learning starts. The pack never includes anyone's recorded voice. With neither its own audio nor a baseline, the voice learning is refused with a message that says what is missing. (#55)

- **One session for every wake word.** The voice-learning program used to teach only "Friday". Now it also records "Sexta-feira" (and any wake word added later that has its recorded introduction): ten beeps per word with the move-to-another-spot step in the middle of each, then thirty seconds of free speech. The session takes about 3.5 minutes with two words. Each word is judged on its own, so one refusal never discards the other word; the other word's recording counts as extra evidence against false activations. Someone already enrolled for Friday is asked only for the missing word. The verifier threshold is shared by all words, so a word that would pass only at another threshold is refused and the message says so. The result (Telegram and spoken) lists each word. (#56)

## Fixes
- **Music stopped on the office satellite after its 22/11 reboot.** The music player runs as another user and could not follow `/etc/asound.conf` into `/etc/friday-satelite`, which is closed to everyone else, so it restarted in a loop. The audio board files now live in `/etc/friday-audio`, readable by the player; a migration moves existing satellites and restarts the player, keeping the old files for a rollback. (#54)
- **The voice invented a music player.** Asked for "my Deezer Flow", the voice model sometimes made up a player name from the satellite's name. A music request now uses the satellite's own player instead of the invented one, answers at once when the player is unavailable, and lets the request through unchanged if Home Assistant takes longer than a second to answer. (#54)
- **The brain could not reach Home Assistant.** OpenClaw's Code Mode ran without the environment the Home Assistant calls need; it is now off and the brain calls Home Assistant through `exec`. (#54)
- **The Alpha promotion sensor showed the wrong alpha.** It showed the newest alpha ("tomorrow") while an older one was promoted at lunch; it now shows the alpha promoted first. The promotion itself is unchanged. (#54)
- **Every announcement clicked before the speech and hissed after it.** The voice model returns a complete audio file, and the server played its header and its closing metadata as sound, near full volume. On 22/11 every saved announcement started with the file header and ended with about 120 bytes of metadata. Now only the audio is played; an audio file that cannot be read fails the announcement instead of playing noise. Saved announcements made before this release are not reused, and the server now keeps the last 100 announcements instead of 200. (#51)
- **Voice learning on the living room satellite recorded everything and then failed.** On 23/11 the learning step stopped with `FileNotFoundError` on `rotulos.json`, a file from the 15/10 archive that exists only on the office satellite, and the voice was not learned. It is now read only when it exists, and takes its negatives from the satellite's own ambient recording. (#55)
- **The assistant explained the machinery.** The wording of the voice-learning tools made it say "o satélite conduzirá o processo". The tool texts now describe what the person lives (beeps, moving, free speech) and the system instruction says the person perceives one assistant. (#55)
