# F.R.I.D.A.Y. 0.4.1: silence stays silent

This is an **alpha** pre-release. It goes to the alpha satellite, the server and the integration first. Stable devices get it after the 48 h soak and the promotion gate below. v0.4.0 keeps its own soak clock and is promoted on its own schedule.

- When she decides not to answer, the voice no longer speaks the marker aloud in any of its forms.

## Fixes
- **Speech gate catches every "no speech" marker.** A one-week review of the gate (12–19/11) found it costs no delay: 183 answers, all released after 0 ms. But 3 turns spoken as `<no speech detected>` or a cut `<no speech` reached the speaker, because the gate matched only `<no speech>` exactly. It now drops any turn that starts with `<no speech`. Normal answers are still released at once (#37).

## Changes by area
- **Voice gateway (VM):** `PortaoDeFala` matches the `<no speech` prefix. No satellite, migration or integration change.

## Promotion gate (stable)
- [ ] In the conversation log, any turn starting with `<no speech` is recorded as `dropped`, and none is heard.
- [ ] `heldMs` on released answers stays near 0.

## All changes
- Speech gate drops every "<no speech" marker variant (#37)
