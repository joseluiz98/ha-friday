# F.R.I.D.A.Y. 0.4.7: updates that only touch the satellite arrive again

This release fixes the update that never reached the office satellite. It carries everything in v0.4.6, which no satellite received.

- A release that leaves the server's update agent unchanged now reaches the satellites.
- If the server refuses an update package again, you are told after an hour instead of finding out on your own.
- From v0.4.6: the satellite no longer ends a conversation while you are still speaking, or as you start a new sentence.
- From v0.4.6: the **Continuous sound cutoff** setting has a short help text in the settings dialog.

## Fixes
- **v0.4.6 never reached the satellite.** It changed no file of the server's update agent, so the agent was rightly not reinstalled and kept the label v0.4.5. The package check compared version labels only, called the agent too old and withheld the package. On 25 Nov the server installed v0.4.6 at 21:54, and the office satellite was still on v0.4.5 the next noon. The check now asks the installer's own question: does this release change the agent's code? If not, the agent is current. If that cannot be proven, the package is still withheld. (#NN)
- **A withheld package was silent.** Nothing was logged, no sensor changed and the satellite looked up to date. A refused or unbuildable package is now logged and counted in **Satellites waiting for the server**, with the reason. (#NN)
- **A file moved out of a component could go unnoticed.** The server compared two releases with rename detection on, which lists only a moved file's new path. Both paths now count. (#NN)
- **The satellite ended the conversation in the middle of a sentence.** Opening a conversation reset "someone is speaking", and speech that never paused sent no new start, so the silence waits closed over it. Speech begun during her answer was also ignored after the microphone reopened. Both now count. (#59)
- **She ended the conversation as a new sentence began.** Her own close, and the thank-you close, now wait while a sentence begun after her answer is still going. (#59)

## Changes by area
- Satellite program: ongoing speech holds the conversation open, and her own close waits for a new sentence. (#59)
- Server agent:
  - An agent whose code matches a release serves that release's package, even with an older version label. (#NN)
  - Withheld packages are logged and listed with the satellites waiting for the server. (#NN)
  - Moved files count as changes when deciding what to reinstall. (#NN)
- Integration: short help text for **Continuous sound cutoff** (Advanced), with the full behaviour in the repository docs. (#59)
- **Migrations:** none.

## Known limits
- With **Continuous sound cutoff** at 0, a sound the satellite takes for a voice and that never pauses, such as the TV, can keep a conversation open until she ends it herself.
